# BATCAVE // Deep Work OS

Batcave-styled deep work command center — timers, non-negotiables, attention analytics, and a 3-day ops calendar.

## Run

```bash
npm install
npm run dev
```

## Features

- Identity protocol, week intention, mental RAM, daily reminders
- Project cards with focus timers + to-dos (Chase Build, My Project, Rav Work, Personal Time)
- Non-negotiable habits with streaks
- Day / Week / Total time summary + all-time attention allocation
- Monthly deep work calendar
- **3-day Google-style calendar** — click-drag to add titled blocks
- Seeded from your existing Claude artifact screenshots (Jul 20–22 2026)
- Persists to `localStorage`

## Stack

Vite + React + TypeScript
