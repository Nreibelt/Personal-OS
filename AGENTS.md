# Agent rules

Rules for Cursor agents working in this repo.

## Screenshots and walkthrough media

- Do not take screenshots or screen recordings unless I explicitly ask.
- Do not use computer-use / browser demos just to show work. Prefer lint, tests, and a short text summary.
- Never save screenshots, videos, GIFs, or walkthrough media into the repo.
- Never git add or commit image/video demo files.
- Do not put screenshots or videos into PR descriptions unless I explicitly ask.
- If verification needs a visual check, say what you checked in plain text instead of capturing media.

## How to talk to me

- Always write at a 4th-grade reading level.
- Explain from first principles: start with the simple idea, then the detail only if needed.
- Use short words and short sentences. Avoid jargon unless I use it first, and then explain it simply.
- Be as concise as possible. Do not leave out anything important.
- Lead with the answer. Then give only the critical why / what to do next.
- No filler, no restating the question, no long preambles.
